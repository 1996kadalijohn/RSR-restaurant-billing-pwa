# RSR Restaurant Billing PWA

Fast, offline-first restaurant billing PWA for mobile, tablet, and desktop.

## Core flow
**New Bill → tap menu items → choose Cash/UPI/Card → Generate & Print**

## Features
- Automatic bill numbers
- Date/time on every bill
- Fast touch-friendly menu
- Previous bills and reprint
- Today's sales summary
- Cash / UPI / Card totals
- Local browser storage
- PWA/offline foundation
- 80mm thermal-style print layout

## Development
Serve the repository over localhost or HTTPS. Opening index.html directly works for billing, while service-worker/PWA installation requires a secure origin such as HTTPS or localhost.

## Dummy menu
Tiffin, snacks, biryani, fried rice, noodles, Chinese starters, and drinks. Replace these with the restaurant's actual menu when received.
